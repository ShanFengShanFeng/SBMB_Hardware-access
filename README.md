# SBMB_Hardware

This page is the public access request entry for the SBMB hardware design files.

[Request access](mailto:jinpeng1@nbu.edu.cn?subject=SBMB_Hardware%20access%20request) by email with your GitHub username and a brief description of your intended use. The maintainer reviews requests individually and will send access instructions to approved applicants.

如需查看或下载硬件设计文件，请[邮件申请](mailto:jinpeng1@nbu.edu.cn?subject=SBMB_Hardware%20access%20request)，注明 GitHub 用户名和简要用途。维护者会逐一审核，并向获批申请者发送访问方式。
